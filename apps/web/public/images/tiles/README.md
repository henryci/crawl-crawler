Tiles in this folder come from Dungeon Crawl Stone Soup's tileset
(crawl-ref/source/rltiles/dngn/gateways in the crawl/crawl repository), which
is derived from the public-domain RLTiles set. Used here for blog banners.

items/ holds item tiles from crawl-ref/source/rltiles/item (armour, shields,
weapons), same source and licence.
